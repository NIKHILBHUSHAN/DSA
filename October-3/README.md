1.majority_Element.py:

find the frequency of each element and find the which element frequency is > n/2 
Using the Boyer–Moore Voting Algorithm:
If an element appears more than half the time it cannot be cancelled out by all the other elements combined.
If the current number matches our candidate, increase the count.
If it differs, decrease the count.
If the count becomes zero, choose the next number as the candidate.

Time Complexity: O(n)

Time Complexity: O(n)
